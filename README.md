# Liying Yang — Academic Homepage

Personal academic website showcasing research in 3D/4D reconstruction and generation.

**Website:** https://liyingcv.github.io/

## Structure

- `index.html`: biography, contact links, and selected publications
- `style.css`: responsive page styles
- `assets/`: profile avatar and research figures
- `.nojekyll`: serve the static files directly with GitHub Pages

No build step or dependencies are required. Open `index.html` to preview locally.

## Updating

Edit the biography or publication entries in `index.html`. Add new images under `assets/`. An asterisk after an author name indicates equal contribution as stated in the original paper.

GitHub Pages serves the `main` branch from the repository root.

## Research images

Figures are from the corresponding papers and official repositories: Uni4R and 4DSTAR (arXiv), BA-LRM (Springer), DS4D and LRGT (LiyingCV), and UMIFormer (GaryZhu1996). The profile avatar is from Google Scholar. Research images remain the property of their respective authors and rights holders.
